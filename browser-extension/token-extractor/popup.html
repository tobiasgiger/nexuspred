Token Extractor Helper

Reads your own tokens from the active discord.com or tradovate.com tab — stays on this machine.
Keep these secret. Each token is like a password for that account — anyone with it gets full access. This extension only shows them to you and never sends them anywhere. Paste them into your own bridge only (Discord Signals for the Discord token; Settings → Token Accounts for Tradovate). Never share them or paste them into any other site.
